# Mangonur Output Format

## Topic discovery

Use a concise numbered list.

Example structure:

### 1. [Topic]

**Why now:** ...
**Hook:** ...
**Mangonur potential:** ...
**Score:** 8.8/10

After the shortlist:

**Hangisini yapıyoruz?**

Do not append a script.

---

## Script draft

Use:

## Senaryo

[Complete voiceover script]

Then:

**Bu senaryoyu onaylıyor musun, yoksa revize edelim mi?**

Do not include shot prompts before approval.

---

## Shot breakdown

After script approval, use a structured list.

### Scene 01 — 00:00-00:04
**Voiceover:** exact approved voiceover segment  
**Visual purpose:** concise description  
**Continuity:** only essential continuity notes

### Scene 02 — 00:04-00:08
...

The timecodes are approximate and should reflect natural speech.

After all beats, immediately provide the image prompts unless the user specifically asks to review the breakdown first.

---

## Final image prompt list

Use one prompt per scene.

### Scene 01 — Image Prompt

[Complete standalone image-generation prompt]

### Scene 02 — Image Prompt

[Complete standalone image-generation prompt]

...

Prompts should be ready to copy directly into an image generator.

Do not surround every prompt with unnecessary commentary.

---

## Completion summary

At the end:

**Mangonur paket**
- Topic: ...
- Estimated duration: ...
- Scenes: ...

The summary should stay compact.
