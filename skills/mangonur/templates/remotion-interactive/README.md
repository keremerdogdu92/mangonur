# Mangonur Interactive Remotion Template

Copy the component pattern into a generated local Remotion project when Studio-editable scene layout is desired. It intentionally exposes only low-risk visual controls.

Editable in Studio where supported:
- scene visual position, scale, rotation;
- caption position, font size, scale and rotation;
- simple inline fade/scale animation keyframes.

Canonical timing, narration alignment, asset approval and filesystem paths remain outside casual Studio editing.
